# job

If you mean **US companies hiring you remotely while you stay in India**, don't search only for `"Remote US"`—that often means **remote within the United States only**.

Use these searches instead:

### LinkedIn

Try:

* `Staff Platform Engineer remote India`
* `Senior DevOps Engineer remote India US company`
* `Staff SRE remote India`
* `Platform Engineer remote APAC`
* `Kubernetes Engineer remote India`
* `DevOps Engineer worldwide remote`
* `Staff Infrastructure Engineer remote India`
* `Platform Engineer "India" "United States"`

Then use filters:

**Location:** India
**Workplace:** Remote
**Experience:** Senior / Director

### Google — often better

Try:

```text
site:boards.greenhouse.io "Platform Engineer" "India" remote
```

```text
site:jobs.lever.co "DevOps Engineer" "India" remote
```

```text
"Staff Platform Engineer" "Remote" "India"
```

```text
"Senior DevOps Engineer" "Remote - India" US
```

```text
"Kubernetes" "Remote - India" "US"
```

### Look for these phrases

These are the important ones:

| Job wording            | What it usually means     |
| ---------------------- | ------------------------- |
| Remote - US            | ❌ US residents only       |
| Remote - USA           | ❌ Usually US only         |
| Remote - North America | ❌ Usually US/Canada       |
| Remote - India         | ✅ You can work from India |
| Remote - APAC          | ✅ Potentially             |
| Remote - Worldwide     | ✅ Best                    |
| Remote - International | ✅ Potentially             |
| Work from anywhere     | ✅ Best                    |
| Global Remote          | ✅ Best                    |
| Contractor - India     | ✅ Potentially             |
| EOR - India            | ✅ Potentially             |

### For your profile, search these titles

I'd prioritize:

**1. Staff Platform Engineer** ⭐
**2. Staff Infrastructure Engineer**
**3. Senior/Staff SRE**
**4. Senior/Staff Cloud Engineer**
**5. Kubernetes Platform Engineer**
**6. Principal DevOps Engineer**
**7. DevSecOps Engineer**

And add:

`AWS + Kubernetes + Terraform + Go`

For example:

> **"Staff Platform Engineer" "Remote - India" Kubernetes AWS Terraform**

That's much more targeted than searching `Remote US`.

If by **"Remote US" you mean you want to work remotely *from the US*** (i.e., relocate to the US but work remotely), that's a different search strategy.
